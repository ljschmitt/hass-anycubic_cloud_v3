# Slicer hardware images

The five PNGs in `hardware_images/` are original Anycubic Slicer Next Workbench artwork. Anycubic retains copyright. The images are distributed with permission for use in Anycubic Cloud and its companion dashboard card.

The images were copied without modification from the Windows Workbench module, file version `2026.09.02.9895068`. The Slicer uses identical PNGs for all brass diameters and identical PNGs for all hardened-steel diameters.
